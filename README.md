# Postcard Pact

Independent community companion app for manual postcard exchanges, friendship tracking, and future remote-trade planning.

Built with **Godot 4.7.1** and **GDScript**. Offline prototype first. Never connects to Pokémon GO.

## Current phase

Offline project foundation — main navigation shell only.

Open this folder in **Godot 4.7.1** (Project Manager → Import / Scan).  
Main scene: `res://scenes/main/Main.tscn`

See [`docs/01_offline_foundation.md`](docs/01_offline_foundation.md) for the Phase 1 checklist.
