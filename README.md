# Postcard Pact

Independent community companion app for manual postcard exchanges, friendship tracking, and future remote-trade planning.

Built with **Godot 4.7.1** and **GDScript**. Offline prototype first. Never connects to Pokémon GO.

## Current phase

Offline project foundation — main navigation shell only.

See [`docs/01_offline_foundation.md`](docs/01_offline_foundation.md) for:

1. Scenes to create manually in Godot
2. Complete `Main.tscn` node tree
3. Portrait stretch settings
4. `mobile_navigation.gd` attachment and signal wiring
5. Test checklist

## Important workflow

Create scenes, nodes, signals, themes, and resources in the Godot editor.

Version-controlled code in this repo is limited to:

- GDScript (`.gd`)
- JSON test data
- Plain-text documentation
